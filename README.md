# 여주시 지속가능발전협의회 홈페이지 리뉴얼 시안

기존 PHP(XpressEngine) 홈페이지(yeoju21.or.kr)의 주요 내용을 서버 프로그램 없이 동작하는 정적 HTML 페이지로 다시 만든 시안입니다.

- `index.html` 홈 (소개 문구, 활동모습, 협의회 소식)
- `about.html` 상임회장 인사말 · 연혁 · 조직도
- `sdgs.html` 지속가능발전목표란? · SDGs 17개 목표
- `action.html` 5개 분과 소개
- `rule.html` 회칙 전문

로그인, 회원가입, 게시판 글쓰기 기능은 없습니다. 소식 목록은 기존 홈페이지의 원문으로 연결됩니다.
